# Mission System V1 — bootstrap addendum

This addendum formalizes the minimum editorial decisions for INITIAL composition.

- Intent has precedence over the noun `evento`: attending is `EXPERIENCE`; organizing, creating, producing, or assembling an event is `PROJECT`.
- M43 may bootstrap `TRAVEL`/`EXPERIENCE` only through a compatible, age-safe canonical action that has no entry prerequisite. Catalog selection occurs in mission; contextual permissions are never bypassed.
- M07 may bootstrap `CAREER_EDUCATION` only for ages 16–18; the youth selects the city in mission.
- M45 is the only generic INITIAL route for `FINANCIAL_GOAL`. It is diagnostic/planning only and cannot initiate selling, work, asking for money, investing, money movement, debt, credit, loans, or unknown contact.
- Career/education goals under age 16 remain `EDITORIAL_GAP_CAREER_EDUCATION_UNDER_16` unless a later canonical mission is approved.
